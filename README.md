# maxVFX Photo Frame Print Tool

어린이집/유치원 등에서 사진을 프레임과 합성하고 실제 mm 기준 A4로 인쇄하기 위한 순수 HTML/CSS/JavaScript 정적 웹 도구입니다.

## 최신 버전

**v0.4.0 — Three-Up & Global A4 Fit Scale**

## 주요 기능

- A4 210 × 297 mm 기준
- 기준 사진 영역 89 × 119 mm
- A4 한 장 최대 3장
- 3장 선택 시 A4 가로 자동 전환
- 사진/프레임/패턴을 함께 줄이는 전체 크기 슬라이더
- 각 사진별 프레임 ON/OFF
- 사진별 독립 이미지 / 프레임 / 패턴 / 텍스트
- 미리보기에서 프레임 직접 선택
- 사진 이동 / 확대 / 회전 / 좌우 반전
- 이름 / 보조 문구 / 시스템 폰트 / 사용자 폰트
- 300 DPI A4 PNG 저장
- 브라우저 직접 인쇄
- 외부 서버/API 없이 로컬 처리

## v0.4.0

### A4 3장 배치

- 1장 / 2장 / 3장 선택
- 3장 선택 시 용지 방향을 자동으로 Landscape(가로)로 고정
- 3개 슬롯의 프레임 두께가 서로 달라도 각각 실제 외곽 크기를 계산
- 프레임을 끈 슬롯은 사진 크기만 레이아웃 계산에 사용
- 재단 가이드 간격까지 고려해 A4 안에서 자동 최대 맞춤

기본값 예시:

- 기준 사진: 89 × 119 mm
- 프레임: 5 mm
- 프레임 포함 외곽: 99 × 129 mm
- 3장 외곽 총 너비: 297 mm

단순 계산상 A4 가로 폭 297 mm에 정확히 맞지만, 실제로는 재단 가이드와 슬롯 사이 간격이 필요하므로 v0.4.0은 자동 Fit Scale을 적용합니다.

기본 재단 가이드 2 mm 기준에서 3장 최대 맞춤은 약 94.6%이며:

- 실제 사진 약 84.2 × 112.6 mm
- 실제 5 mm 프레임 약 4.7 mm

로 함께 줄어듭니다.

### 전체 크기 슬라이더

전체 크기 슬라이더 범위: 40% ~ 100%

- 100% = 현재 사진 기준 크기를 넘지 않는 범위에서 A4에 들어가는 최대 크기
- 기준 사진 크기가 A4에 그대로 들어가면 100% = 원래 크기
- 3장처럼 공간이 부족하면 자동 Fit Scale이 먼저 계산되고, 슬라이더는 그 최대값을 기준으로 추가 축소
- 사진 크기, 프레임 두께, 둥근 정도, 패턴 크기, 패턴 간격이 같은 비율로 축소
- 슬롯별 이미지 Crop/Zoom/Pan 상태는 유지

예:
- 자동 최대 맞춤 94.6%
- 전체 크기 슬라이더 80%
- 실제 적용 배율 = 94.6% × 80%

### 프레임 ON/OFF

각 사진 슬롯마다 프레임 사용 토글을 제공합니다.

OFF 시:

- 프레임 배경 제거
- 라인 제거
- 패턴 제거
- 프레임 두께가 레이아웃 공간에서 제외
- 다른 슬롯의 최대 크기 계산에도 즉시 반영

ON/OFF 상태는 슬롯별 독립입니다.
