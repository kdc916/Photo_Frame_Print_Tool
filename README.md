# maxVFX Photo Frame Print Tool

어린이집/유치원 등에서 사진을 프레임과 합성하고 실제 mm 기준 A4로 인쇄하기 위한 순수 HTML/CSS/JavaScript 정적 웹 도구입니다.

## 최신 버전

**v0.3.2 — Continuous Perimeter Pattern Spacing**

## 주요 기능

- A4 210 × 297 mm 기준
- 기본 사진 영역 89 × 119 mm
- A4 한 장 최대 2장
- 사진별 독립 이미지 / 프레임 / 패턴 / 텍스트
- 미리보기에서 프레임 직접 선택
- 사진 이동 / 확대 / 회전 / 좌우 반전
- 이름 / 보조 문구 / 시스템 폰트 / 사용자 폰트
- 300 DPI A4 PNG
- 브라우저 직접 인쇄
- 외부 서버/API 없이 로컬 처리

## v0.3.2

### 장식 패턴 전체 둘레 균등 배치

이전 버전은 위/아래/좌/우 네 변을 각각 나눠 패턴을 계산했기 때문에 모서리에서 서로 다른 변의 패턴 2개가 가까이 붙어 보일 수 있었습니다.

v0.3.2부터 도트 / 다이아몬드 / 별 / 하트 / 꽃 패턴은 프레임의 둥근 사각형 중심선을 하나의 연속 둘레로 계산합니다.

- 전체 둘레 길이 계산
- 패턴 크기 + 패턴 간격으로 전체 패턴 개수 결정
- 남는 길이를 전체 둘레에 다시 균등 분배
- 시작 위치는 실제 간격의 1/2만큼 이동해 특정 모서리에 패턴이 고정되지 않게 처리
- 직선과 모서리 곡선 사이에서도 동일한 중심 간격 유지
- 패턴 크기가 커지면 개수가 자동 감소
- 패턴 크기가 작아지면 개수가 자동 증가

따라서 모서리만 2개가 붙거나 특정 위치에 패턴이 고정되는 현상을 제거했습니다.

## 회귀 방지

- 기본 사진 89 × 119 mm
- A4 세로 2480 × 3508 px @ 300 DPI
- A4 가로 3508 × 2480 px @ 300 DPI
- A4 한 장 최대 2장
- slot.frame 독립 구조 유지
- Photo Bleed → Frame Overlay 렌더 순서 유지
- 장식형 패턴은 전체 둥근 프레임 둘레를 하나의 연속 경로로 계산
- 사진/폰트 서버 업로드 없음
