# maxVFX Photo Frame Print Tool

어린이집/유치원 등에서 사진을 귀여운 프레임과 합성하고 A4로 인쇄하기 위한 **순수 HTML/CSS/JavaScript 정적 웹 도구**입니다.

## 주요 기능

- A4 210 × 297 mm 기준 작업
- 기본 사진 영역 89 × 119 mm
- 1장 / 2장 / 4장 A4 배치
- 각 칸에 서로 다른 사진 삽입
- 사진 드래그 이동, 확대, 회전
- 프레임 두께 / 색상 / 둥근 모서리
- 단색, 이중선, 점선, 도트, 스트라이프, 스캘럽, 컨페티, 크레용 스타일
- 종이 / 점박이 / 소프트 그레인 질감
- 점선, 실선, 재단 표시, 복합 가이드
- 사진 안전영역 표시
- 300 DPI A4 PNG 저장
- 브라우저 직접 인쇄
- 외부 라이브러리, 서버, API 없음

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다.

로컬 서버가 필요하면:

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.

## GitHub Pages 배포

1. 저장소 루트에 이 폴더의 파일을 업로드합니다.
2. GitHub 저장소 → **Settings → Pages**
3. **Deploy from a branch** 선택
4. `main` 브랜치 / `/ (root)` 선택
5. Save

빌드 과정은 필요 없습니다.

## 인쇄 권장

- 브라우저 인쇄 배율: **100% / 실제 크기**
- 여백: 없음 또는 최소
- 머리글/바닥글: 끔
- 배경 그래픽: 켬 권장

PNG 저장은 A4 300 DPI 기준으로 생성됩니다.

- 세로: 2480 × 3508 px
- 가로: 3508 × 2480 px
