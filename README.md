# maxVFX Photo Frame Print Tool

어린이집/유치원 등에서 사진을 프레임과 합성하고 실제 mm 기준 A4로 인쇄하기 위한 순수 HTML/CSS/JavaScript 정적 웹 도구입니다.

## 최신 버전

**v0.3.1 — Pattern Alignment & Direct Frame Selection**

## 주요 기능

- A4 210 × 297 mm 기준
- 기본 사진 영역 89 × 119 mm
- A4 한 장 최대 2장
- 사진별 독립 이미지 / 프레임 / 패턴 / 텍스트
- 미리보기에서 프레임 직접 선택
- 사진 이동 / 확대 / 회전 / 좌우 반전
- 이름 / 보조 문구 / 시스템 폰트 / 사용자 폰트
- 300 DPI A4 PNG
- 브라우저 직접 인쇄
- 외부 서버/API 없이 로컬 처리

## v0.3.1

### 패턴 정렬 개선

장식형 패턴은 프레임 띠 전체를 타일처럼 채우지 않고 **프레임 둘레 중심선**에 맞춰 배치합니다.

대상:

- 도트
- 다이아몬드
- 별
- 하트
- 꽃

개선 내용:

- 패턴 중심이 프레임 두께 중앙에 위치
- 네 모서리에는 안전 여백 적용
- 위/아래, 좌/우가 같은 간격 리듬으로 배치
- 큰 다이아몬드가 사진 안쪽이나 프레임 바깥으로 반쯤 잘리는 현상 완화
- 패턴 크기가 프레임 두께보다 클 경우 자동 제한
- 장식형 패턴 선택 시 패턴 크기 슬라이더 최대값도 현재 프레임 두께에 맞춰 자동 변경

체크 / 줄무늬 / 물결 / 지그재그도 프레임 중앙 기준으로 패턴 시작 위치를 계산해 좌우/상하 균형을 개선했습니다.

### A4 미리보기에서 프레임 직접 선택

- 사진 영역: 기존처럼 사진 드래그 편집
- 프레임 테두리: 클릭하면 해당 슬롯 선택
- 선택 즉시 3. 프레임 / 패턴 영역으로 자동 스크롤
- 선택된 프레임은 미리보기에서 바깥쪽 점선으로 표시
- 프레임 위 마우스 커서는 pointer, 사진 위는 grab으로 구분

따라서 2번 프레임을 수정하기 위해 먼저 2. 사진까지 올라가 슬롯을 선택할 필요가 없습니다.
