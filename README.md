# maxVFX Photo Frame Print Tool

어린이집/유치원 등에서 사진을 프레임과 합성하고 실제 mm 기준 A4로 인쇄하기 위한 순수 HTML/CSS/JavaScript 정적 웹 도구입니다.

## 최신 버전

**v0.3.0 — Independent Frame & Pattern Engine**

## 주요 기능

- A4 210 × 297 mm 기준 작업
- 기본 사진 영역 89 × 119 mm
- **A4 한 장 최대 2장**
- 1장 / 2장 배치
- 사진별 독립 이미지
- **1번/2번 프레임 완전 독립 설정**
- 사진 드래그 이동 / 확대 / 회전 / 좌우 반전
- 이름 / 보조 문구를 사진별로 추가
- 시스템 설치 폰트 검색
- TTF / OTF / WOFF / WOFF2 폰트 직접 불러오기
- 300 DPI A4 PNG 저장
- 브라우저 직접 인쇄
- 사진/폰트 서버 업로드 없음

## v0.3.0 변경 내용

### A4 배치

- 4장 배치 제거
- A4 한 장에 최대 2장으로 제한
- 세로 A4에서는 2장을 위/아래 배치
- 가로 A4에서는 공간이 충분하면 좌/우 배치
- 각 슬롯의 프레임 두께가 달라도 실제 외곽 크기로 레이아웃 계산
- 프레임끼리 겹치지 않도록 8 mm 기본 간격 적용

### 슬롯별 독립 프레임

1번 사진과 2번 사진이 각각 다음 값을 따로 가집니다.

- 프레임 프리셋
- 테두리 형태
- 프레임 배경색
- 라인 색
- 프레임 두께
- 둥근 정도
- 패턴 종류
- 패턴 색상 1 / 2
- 패턴 크기
- 패턴 간격
- 랜덤성
- 랜덤 시드
- 질감 / 질감 강도

프레임 설정을 다른 칸에 복사 버튼으로 현재 프레임만 복사할 수 있습니다.

### 패턴 엔진

지원 패턴:

- 도트
- 사선 줄무늬
- 체크
- 다이아몬드
- 별
- 하트
- 꽃
- 물결
- 지그재그
- 컨페티
- 스프링클
- 크레용

프레임의 기본 배경 단색 위에 패턴을 별도 합성하는 구조입니다.

도트 패턴은 랜덤 좌표가 아니라 프레임 각 변을 기준으로 개수를 계산한 뒤 동일 간격으로 재분배하므로 원의 크기와 간격이 일정합니다.

컨페티/스프링클/크레용/장식 패턴은 랜덤 시드를 사용해 렌더할 때마다 모양이 흔들리지 않습니다. 시드 변경을 누를 때만 새로운 배열을 만듭니다.

## 인쇄 기준

- A4 세로: 210 × 297 mm → 2480 × 3508 px @ 300 DPI
- A4 가로: 297 × 210 mm → 3508 × 2480 px @ 300 DPI
- 기본 사진: 89 × 119 mm

브라우저 인쇄 시 배율은 100% / 실제 크기, 여백 없음 또는 최소, 머리글/바닥글 끔을 권장합니다.

## 실행

index.html을 브라우저에서 열면 바로 사용할 수 있습니다.

GitHub Pages에서는 저장소의 main / root 정적 배포를 사용합니다.
